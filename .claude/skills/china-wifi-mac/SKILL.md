# china-wifi-mac — проводник по настройке

Ты ведёшь человека по README этого репозитория. Он не технарь, пишет по-русски. Схема:
`iPhone ─USB─► Mac («Общий интернет» → Wi-Fi) ─Wi-Fi─► устройство`, трафик устройства → `pf rdr` → sing-box → VPN Мака (Monkey Speed, GlobalMode) → Китай.

## Два факта, которые определяют порядок

1. **Как только на Маке включён Monkey GlobalMode, ты недоступен**: Claude не работает из Китая. Всё, что после этого момента, человек делает сам по заранее выданным командам. Скажи ему это прямо и заранее.
2. **Кабель iPhone — раньше, чем отключение от домашнего Wi-Fi.** Пока GlobalMode выключен, твоя сессия живёт через кабель. Отключишь Wi-Fi до кабеля — потеряешь сеть сам.

`sudo` ты не вводишь: пароль печатает человек. В Claude Code это `! sudo zsh car-vpn.sh car` (префикс `!` запускает команду в его терминале).

## Этап 1 — собрать цепочку (ты на связи)

1. Запусти `zsh car-vpn.sh check`. Каждое ❌ сопровождается строкой `→` с точным действием — передай её человеку дословно, не придумывай свои пути в настройках. Таблица «Что не так» в README повторяет их.
2. Порядок устранения: iPhone USB → Wi-Fi Мака свободен → «Общий интернет» (Share from: iPhone USB, To: Wi-Fi) → sing-box. Пункт «VPN Мака» на этом этапе ❌ — это норма.
3. Повторяй `check` после каждого действия человека. Цель этапа: пункты 1–3 ✅ (⚠️ «никто не подключён» допустимо).
4. Если `«Общий интернет» не работает (нет bridge100)` держится: сначала закрой все ❌ выше, затем выключить/включить «Общий интернет»; если и это не помогло — выдернуть кабель, выключить/включить Режим модема на iPhone, вставить кабель, «Доверять», снова «Общий интернет». Перезагрузка Мака — последнее.

Ничего, кроме `check`, на этом этапе не запускай. Никаких своих правил `pfctl`. `route-to` в туннель VPN запрещён: на macOS 26.1 это дважды дало kernel panic.

## Этап 2 — передача (ты отключаешься)

Когда 1–3 ✅, выдай одним сообщением, в этом порядке:

1. Предупреждение: «Сейчас вы включите Monkey GlobalMode, и я замолчу до тех пор, пока вы его не выключите. Это нормально.»
2. Monkey Speed на Маке: GlobalMode (全局) → сервер Пекин (北京) → подключить.
3. `zsh car-vpn.sh check` — должно быть `✅ Мак выходит через Китай: … 中国 北京 …` и `=== Всё готово.`. Если 香港 — сменить сервер на Пекин. Если «не через Китай» — переподключить Monkey.
4. На устройстве: Настройки → Wi-Fi → сеть Мака, пароль из настроек «Общего интернета».
5. `sudo zsh car-vpn.sh car` (пароль Мака не отображается при вводе), затем сразу открыть на устройстве QR. Что считать успехом: строки `→ …`, среди них на Voyah `→ 8.136.x.x:1663`; QR появляется за ~10 с.
6. Если в окне появилось `⚠️ VPN Мака отвалился` — переподключить Monkey, запустить `car` снова, переоткрыть окно QR.
7. Закончили — Ctrl+C, выключить GlobalMode, вернуться сюда и прислать `secrets/car-vpn.log`. Аварийно: `sudo zsh car-vpn.sh off`.

## Этап 3 — разбор журнала после возврата

Читай `secrets/car-vpn.log`, не исходник скрипта. Строки:

| В журнале | Значит |
|---|---|
| `inbound/redirect[car]: inbound connection to X` | устройство открыло соединение к X, оно ушло через sing-box (в окне это `→ X`) |
| `… to 8.136.147.132:1663` / `8.136.127.53:1663` | сервер входа Voyah; есть эта строка — QR должен был появиться |
| `… to 172.16.106.20:7` | служебная проверка HarmonySpace, игнорировать |
| `ERROR network: missing default interface` | у Мака пропал маршрут: отвалился туннель Monkey или кабель iPhone; всё после этого момента не работает |
| `dial tcp …: no route to host` | следствие предыдущего |
| строк `inbound/redirect` нет вообще | устройство не было в Wi-Fi Мака или ничего не открывало |

Диагноз строй по двум вопросам: (а) был ли обрыв (`missing default interface`) и когда; (б) дошло ли устройство до нужного сервера (для Voyah — `:1663`). Нет `:1663` без обрыва — устройство не попробовало войти: переоткрыть окно QR, выключить/включить Wi-Fi устройства, запустить `car` заново. Был обрыв — Monkey нестабилен: переподключить и повторить, при повторах сменить пекинский сервер.

Отвечай человеку по-русски, коротко: что случилось (с временем из журнала), что сделать, в каком порядке. Следующие шаги он снова делает без тебя — скажи это.
